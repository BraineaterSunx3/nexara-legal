# Nexara – Rechtliche Informationen

Statische Webseite mit Impressum, Datenschutzerklärung und Nutzungsbedingungen
für die App "Nexara". Gedacht zum Hosting über GitHub Pages.

## Struktur
- `index.html` – Startseite mit Links zu den drei Dokumenten
- `impressum.html`
- `datenschutz.html`
- `nutzungsbedingungen.html`
- `style.css` – gemeinsames Stylesheet
- `.nojekyll` – verhindert, dass GitHub Pages die Dateien durch Jekyll verarbeitet
